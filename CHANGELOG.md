# Changelog

All notable constitution changes are documented here.

## 1.0.1 - Unreleased

- Expanded mandatory Java guidance for JDBC value binding, dynamic SQL identifier validation, bounded large-data retrieval, deterministic resource cleanup, and global mutable state lifecycle control.
- Expanded mandatory Spring guidance for service clients and scheduled job configuration.
- Added API compatibility obligations for routes, HTTP methods, payload shapes, and status-code semantics.
- Added the `framework.react-native` constitution module for bare React Native applications.
- Added a sample React Native project configuration.
- Added universal requirements for tracing changes to accepted requirements, recording human approvals, linking evidence of executed tests, and recording documentation impact.
- Expanded the React Native PR checklist with requirement, test-execution evidence, documentation-impact, and human-approval items.

## 1.0.0 - Initial Release

- Added the initial engineering constitution repository structure.
- Added universal, language, framework, platform, and middleware modules.
- Added CXF and OSGi middleware constitution modules.
- Added sample project module-selection configurations.
- Added a JSON Schema for project configuration files.
