# Carbon Constitutions

These constitutions describe Entgra's Carbon-based component and webapp development conventions.

- [CXF webapps](cxf-webapps/cxf-webapps.md): module `middleware.cxf`, covering CXF/JAX-RS WARs, API contracts, and feature packaging.
- [OSGi components](osgi-components/osgi-components.md): module `middleware.osgi`, covering services, persistence, tenant context, and component lifecycle.

The existing documents were moved without changing their contents or metadata. Their historical module IDs remain valid; project selections and module dependencies do not change.

References to the old paths inside the original documents have been left untouched to preserve their contents. Use the links above or the [relocation table](../../README.md#relocated-files) to find the current files.

The existing root README, changelog, and ownership configuration have also been left unchanged. The Carbon paths currently inherit the default repository owners; the original middleware ownership entry has not been edited.
